INFINTIME

## Description

Le projet en cours de construction est une plateforme visant essentiellement les entrepreneurs (quels qu'ils soient), à pouvoir consulter leur agenda de RDV à prendre ou pris, prendre des notes pour ne rien oublier, et d'autres fonctionnalités.

Pour les clients potentiels, un espace où les clients potentiels pourront prendre RDV pour d'éventuels travaux, ou demande de devis.

## Fonctionnalités

 Inscription / connexion utilisateur (entrepreneur)
 Espace entrepreneur : agenda des RDV (à venir / passés)
 Gestion des créneaux de disponibilité
 Prise de RDV côté client (sans compte ou avec compte)
 Prise de notes liées à un RDV
 Formulaire de contact / demande de devis
 Affichage des données (dashboard entrepreneur)

## Technologies utilisées
FrontEnd : React (Vite), HTML, CSS
BackEnd : PHP
Base de données : à définir

Installation

## Pour tester le projet en local :

Cloner le dépôt
bash
   git clone <url-du-depot>

## Installer et lancer le FrontEnd
bash
   cd FrontEnd
   npm install
   npm run dev
## Installer et lancer le BackEnd
bash
   cd BackEnd
   npm install
   npm start
